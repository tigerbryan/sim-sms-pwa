# 公开版隐私与来源说明

此仓库来自独立的源码快照，不导入个人部署的 Git 历史。只复制可发布的代码、测试、许可与泛化示例，重写部署和使用文档。

不包含：运行数据库/短信/验证码、账号密码、Cookie、SSH/推送私钥、订阅端点、SIM/设备唯一标识、家用网络地址、私人服务域名、运行日志、真实截图、私有备份或已经部署的二进制。

示例截图使用虚构号码和内容。代码里的测试凭据/测试号码只用于隔离单元测试，不能用于生产；vendor 中上游依赖的公开密码学测试夹具保留其许可，扫描豁免仅针对明确的夹具路径。

`python3 scripts/check-public-tree.py` 检查被跟踪的公开文件清单、私钥/令牌格式、运行文件类型、私有主机地址、绝对用户目录，以及本地 Markdown 链接。它不是完整 DLP/安全审计，不能证明未知秘密绝不存在。发布流程还运行 redacted Gitleaks 扫描并检查构建产物。不要将扫描报告（可能带匹配值）提交到公开库。

GitHub 仓库所有者、提交者的公开账号和项目来源链接是开源必要元数据。提交采用 GitHub noreply 邮箱，不发布个人联系邮箱；这不等于匿名发布。

应用实际部署后会保存用户的真实短信与通知订阅。SQLite 中短信正文不是全库加密；推送相关密钥、订阅、待发内容使用 master.key 加密，主密钥位于本机。备份包含解密所需材料，必须用自己的加密存储保护。
